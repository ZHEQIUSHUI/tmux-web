# tmux-web 安卓 App

和 Mac App 一样是个「壳」：直接打开服务器上的 tmux-web 网页，或者在 App 里维持一条 SSH 端口转发再打开。网页内容由服务器提供，服务器更新后点顶部的刷新就是新版。App 自己的界面（首页、连接页、设置）用 Jetpack Compose + Material 3。

## 安装和使用

1. 下载 [tmux-web-android.apk](https://github.com/ZHEQIUSHUI/tmux-web/releases/latest/download/tmux-web-android.apk)，点开安装（系统可能要求允许「安装未知应用」）。Android 8 起。
2. 打开后是服务器首页，第一次会让你选连接方式：
   - **直接访问**：已经能直接访问服务器时用（比如在 EasyTier、局域网里），只填网址，比如 `http://10.126.126.2:8080`
   - **SSH 转发**：通过 SSH 端口转发访问，填下面这些：
   - **SSH 目标**：`user@host`
   - **SSH 端口**、**服务器上 tmux-web 的端口**（默认 8080）、**本地端口**（每台服务器自动分配一个：18080、18081…，固定不变，网页的登录状态才能保留）
   - **SSH 密码**：可选，留空则需要时弹框输入；右边的小眼睛切换明文 / 圆点
   - **SSH 私钥**：可选，粘贴私钥内容，或者「从文件导入」
   - 本地端口、远端地址、「忘记主机密钥」在「高级」里；填错的地方当场标红，「测试连接」先看看连不连得上
3. 点「保存并连接」。连接页一步步显示进度（SSH 登录 → 端口转发 → 打开网页），需要验证码时会弹框输入；失败时说明原因和该怎么办，可以重试或直接去改设置。

### 用起来

- **首页**：每台服务器一张卡片，最近用过的排在前面；卡片上显示是否在线和延迟（每半分钟检测一次，下拉立即检测）、上次使用时间。点卡片就连接，已经连着的直接回到页面；⋮ 或长按：连接、编辑、复制一份、删除。右上角可以搜索。平板上卡片排成多列。
- **页面**：顶栏左边 ← 回首页（连接保留），中间是服务器名，点它弹出所有服务器，一点就换一台；右边刷新和 ⋮（编辑此服务器、断开连接、检查更新）。连接断了会在顶部显示「正在重新连接」，页面不动。
- 一次连一台服务器；界面跟随系统深色 / 浅色，Android 12 起跟随壁纸取色。

## 功能

- 内置 SSH（sshj），支持私钥、密码、验证码（两步验证），断线自动重连
- 在后台保持连接（通知栏里有一条「已连接」），网页的「等待确认 / 任务完成」提醒变成系统通知，点通知跳到对应会话
- 配置（包括密码和私钥）用安卓系统密钥库加密保存
- 服务器的主机密钥第一次连接时记住，之后变了会拒绝连接（防冒充）；服务器重装过的话在「编辑服务器 → 高级」里点「忘记主机密钥」
- 平板自动用电脑版布局，手机用手机版；网页「我的」菜单里可以手动切换（自动 / 手机版 / 电脑版）
- 首页右上角 ⋮ 和底部都有「检查更新」，随时手动检查；也会自动检查更新（通过你的 tmux-web 服务器，取不到时同时试 GitHub、国内的 GitHub 加速和南京大学的 GHCR 镜像，用最先响应的那个；文件都按 SHA-256 校验），提示后下载安装
- 返回键在网页里后退，退到底回首页；在首页按返回键 App 转到后台，连接和提醒照常

## 编译

```sh
cd android
./gradlew assembleDebug        # → app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` 里写 `sdk.dir=<安卓 SDK 路径>`（需要 platform 35 和 build-tools 35.0.0）。

## 发版（CI）

`.github/workflows/apps.yml` 同时编译 Mac 和安卓版，发布到唯一的一个 GitHub Release「latest」（每次替换，下载链接不变），并生成 `version.json` 给 App 检查更新用。版本标识自动生成（日期 + 编译序号，比如 `2026.10.8.12`），不用手动管理。

- `mac/`、`android/` 下的代码有改动推送到 main 时自动运行；只改网页不会触发
- 也可以在 GitHub 的 Actions → Apps → Run workflow 手动运行（可以填更新说明）

### 签名密钥

安卓 App 每次更新必须用同一个密钥签名，否则无法覆盖安装。为了省去配置，签名密钥直接放在仓库里（`android/release.jks`，密码写在 `app/build.gradle.kts` 里），是公开的。这意味着任何人都能用它签名一个看起来是「tmux-web」的安装包，所以**请只从本项目的 GitHub Release 下载安装**。想用自己的密钥，设置环境变量 `TW_KEYSTORE`（密钥文件路径）和 `TW_KEYSTORE_PASSWORD` 即可。
