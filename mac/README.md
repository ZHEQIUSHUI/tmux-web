# tmux-web 的 Mac App

一个「壳」App：它在后台维持到服务器的连接（SSH 端口转发、直接访问，或 App 内置的 EasyTier，可以同时连多台），在自己的窗口里打开 tmux-web 网页。网页内容还是由服务器提供，服务器上更新了网页，App 里也跟着更新（需要时点右上角的 ⟳ 或按 ⌘R 刷新）。

## 使用

1. 下载 [tmux-web-mac.zip](https://github.com/ZHEQIUSHUI/tmux-web/releases/latest/download/tmux-web-mac.zip)，解压，把 `tmux-web.app` 拖进「应用程序」。
2. **在终端执行一次**（App 没有苹果开发者签名，不执行的话系统会拦着不让打开）：
   ```sh
   xattr -c /Applications/tmux-web.app
   ```
3. 打开后是首页（服务器卡片），第一次会让你选连接方式：
   - **直接访问**：已经能直接访问服务器时用（比如在 EasyTier、局域网里），只填网址，比如 `http://10.126.126.2:8080`
   - **内置 EasyTier**：App 自己启动 EasyTier Core，不需要另外打开 EasyTier App。填网络名称、网络密钥、公共节点和服务器在 EasyTier 里的 IPv4 地址；它用 no-TUN 模式把一个本地端口转发到服务器上的 tmux-web，不会占用系统 VPN，也不需要管理员权限。公共节点可以填多个（逗号或换行分隔），例如 `tcp://public.example.com:11010`。高级里可以换本地端口。
   - **SSH 转发**：通过 SSH 端口转发访问，填下面这些：
   - **SSH 目标**：`user@host`，或者 `~/.ssh/config` 里的别名（这样端口、跳板机、密钥都按配置来）
   - **服务器上 tmux-web 的端口**：默认 8080
   - **SSH 私钥**、**密码**：都可选。选了公钥 `.pub` 也可以，会自动用同名的私钥；密码留空则需要时弹框输入
   - 「高级」里有本地端口（每台服务器自动分配一个：18080、18081…，固定不变，网页的登录状态才能保留）、远端地址、其他 ssh 参数（比如 `-J 跳板机`）
   - 填错的地方当场标红；「测试连接」先看看服务器通不通
4. 点「保存并连接」。连接页一步步显示进度（建立连接 → 打开网页）；连不上时说明原因和该怎么办，可以直接重试或改设置。

### 日常使用

- **首页**：每台服务器一张卡片，显示是否在线和延迟（自动检测）、上次使用时间，最近用过的排在前面，可以搜索。点卡片打开；⋯ 或右键可以编辑、复制一份、删除。
- **多台同时连着**：打开过的服务器都保持连接，切换时直接切过去，页面状态不丢；每台的提醒都会变成系统通知（通知里写着是哪台）。首页上连着的卡片标着「已连接」，悬停可以「断开」。
- **标题栏**：▦ 回首页（⌘L）；旁边的服务器名（带状态点）点开就能切到别的服务器；右边 ⟳ 刷新网页（⌘R），⋯ 里有编辑此服务器、在浏览器中打开、断开、检查更新。

## 功能

- 服务器配置和密码加密保存（AES-GCM，密钥放在只有你自己能读的文件里，完全不用钥匙串，任何时候都不会要电脑的登录密码）；权限太宽的私钥只在登录时临时用一份副本，登录后立即删除
- 用系统自带的 `ssh`，`~/.ssh/config`、密钥、`ssh-agent`、`known_hosts` 全部照常生效
- 内置 EasyTier Core（固定版本，构建时下载并校验 SHA-256）使用 no-TUN + TCP 端口转发；网络密钥写在权限 `0600` 的临时 TOML 里，不放在进程参数中，停止连接时删除。EasyTier 断线也会像 SSH 一样自动重连
- 断线自动重连；App 退出或崩溃时转发也跟着关闭，不会残留
- 网页的「等待确认 / 任务完成」提醒会变成 **macOS 系统通知**（只在你没看着窗口时发），点通知直接跳到那个会话
- 能上传、下载文件（下载到「下载」文件夹），「打开原图」会开新窗口
- 关掉窗口 App 不退出（通知照常收），点程序坞图标就回来；⌘Q 才退出
- 菜单栏「服务器」里有首页（⌘L）、新建（⌘N）、各台服务器（带状态点）、重新连接（⌘⇧R）、编辑 / 断开当前服务器、断开全部
- 双击标题栏按「系统设置 → 桌面与程序坞 → 连按窗口标题栏以」的设置执行（默认填满屏幕，再双击恢复）
- 自动检查更新（每 6 小时，或菜单「tmux-web → 检查更新…」），通过你的 tmux-web 服务器下载，取不到时同时试 GitHub、国内的 GitHub 加速和南京大学的 GHCR 镜像，用最先响应的那个（文件都按 SHA-256 校验）；更新时自动替换并重启。需要 App 放在「应用程序」里才能原地更新

## 局域网共享配置

首页的「共享配置」（菜单栏「服务器 → 共享配置…」也有）可以在两台设备之间直接传输服务器配置和 SSH 私钥，不需要先导出文件。

- **共享给其他设备**：勾选要发送的服务器和私钥，设置端口（默认 `48620`）与至少 6 位访问密码，点「开始共享」。窗口会列出本机的所有局域网 IPv4 地址，另一台设备填入 `IP:端口` 和密码即可获取。
- **从其他设备获取**：打开「从其他设备获取」，填对方显示的 IP、端口和密码。导入的服务器会分配新的本地 UUID 和空闲本地转发端口，不会覆盖本机已有配置；导入的私钥保存在 `~/Library/Application Support/TmuxWeb/shared-keys/`，权限为 `0600`。
- **查重**：私钥按规范化后的文本 SHA-256 指纹比较，同一把私钥只保留一份并复用。SSH 服务器按账号、主机、SSH 端口、远端地址与端口、密码、私钥指纹和额外参数比较；内置 EasyTier 服务器按网络名称、网络密钥、公共节点（顺序无关）、服务器虚拟 IP 和 tmux-web 端口比较；直连地址会先规范化协议、主机、默认端口和末尾斜杠。完全相同的配置直接跳过，同一主机但凭据不同则保留为独立配置。
- **安全**：共享内容用 AES-256-GCM 加密，密钥由访问密码经 PBKDF2-HMAC-SHA256（120,000 次）派生，访问密码不会保存。接收端连续输错 5 次会锁定 60 秒。只在可信局域网使用，不要把共享端口暴露到公网；窗口关闭后共享仍会继续，直到点「停止共享」或退出 App。
- Mac 平时不保存私钥口令。共享加密私钥时可以在发送页填一次口令，Android 接收后会一并保存；Mac 接收方不会保存口令，连接时由系统 `ssh` 询问。

## 编译（在 Mac 上）

```sh
xcode-select --install   # 第一次需要
./build.sh               # → build/tmux-web.app、build/tmux-web-mac.zip（Apple 芯片 + Intel，macOS 13 起）
```

`build.sh` 会把 EasyTier `v2.6.4` 的 arm64 和 x86_64 Core 下载到 `.build/easytier/`，校验 SHA-256 后放进 App。第一次构建需要能访问 GitHub；网络受限时可以用 `EASYTIER_BASE_URL` 指向同一版本文件的镜像目录。EasyTier 以 LGPL-3.0 分发，许可证和第三方声明会一起放进 App，详见 `THIRD_PARTY_NOTICES.md`。
